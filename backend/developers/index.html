Build a bot for Hushavia

Bots are accounts that a program runs. People chat with them, press their buttons, add them to groups and open their mini apps. You write the program in any language — it talks to Hushavia over simple HTTPS requests.

1 · Create the botIn the Hushavia app open @BotForge → New bot (or Settings → My bots). You get its key.
2 · Call the APIPOST /api/bots/v2/<method> with the header X-Bot-Key.
3 · Answer eventsRead new messages and button presses with events.poll, or get them on your server with a hook.

Quick start

Every call is a POST (or GET) to /api/bots/v2/<method>. Send parameters as JSON, a form, or multipart (for files). Put the key in the X-Bot-Key header (Authorization: Bearer <key> works too).

curl -X POST /api/bots/v2/profile.get -H "X-Bot-Key: hsv_123_yourSecretKey"

Every answer looks like one of these:

{ "ok": true,  "data": { … } }
{ "ok": false, "error": { "code": "chat_not_found", "message": "…", "retry_after": 3 } }
Keep the key secret. Anyone with it controls your bot. Never put it in an app, a web page or a public repository. If it leaks, open @BotForge → your bot → New key: the old one stops working at once.

Limits

  • 120 calls per 10 seconds per bot. Above that you get 429 with retry_after (seconds).
  • Text: up to 4,096 characters; captions up to 1,024. Button data: up to 64 bytes.
  • Events not read within 24 hours are dropped (at most 1,000 waiting per bot).
  • A bot only sees a person after they open it (press Start) or meet it in a group.

Events

Each event has event_id, kind and at, plus one object named after its kind.

kindWhat happened
messagemessage: {id, conversation, author, sent_at, text, reply_to, topic, attachment, place}
button_presspress: {id, data, message_id, conversation, author} — answer it with button.reply
member_joinedmember_joined: {conversation, people} — in groups
member_leftmember_left: {conversation, person}
join_requestjoin_request: {conversation, person} — for admin bots in groups that approve new members
inline_searchsearch: {id, query, author}
app_dataapp_data: {data, button, conversation, author} — sent by your mini app

In groups with privacy on (the default) the bot only gets messages that start with “/”, mention it, or reply to it. Turn privacy off in @BotForge to get every message.

Hooks

With a hook, Hushavia sends each event to your https address as a POST with a JSON body. Answer with any 2xx status. If your server is down, events wait and are sent again later.

Every hook request is signed: X-Hushavia-Signature: sha256=<hex> is the HMAC-SHA256 of the raw body with your secret. Check it before you trust a request:

# Python
import hmac, hashlib
def genuine(raw_body: bytes, header: str, secret: str) -> bool:
    good = "sha256=" + hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(good, header or "")
// Node.js
const crypto = require('crypto');
const genuine = (rawBody, header, secret) => {
  const good = 'sha256=' + crypto.createHmac('sha256', secret).update(rawBody).digest('hex');
  return header && good.length === header.length && crypto.timingSafeEqual(Buffer.from(good), Buffer.from(header));
};

Examples

Python — an echo bot with buttons (no library needed)

import requests

API = "/api/bots/v2/"
KEY = "hsv_123_yourSecretKey"        # better: read it from an environment variable

def call(method, **params):
    r = requests.post(API + method, json=params, headers={"X-Bot-Key": KEY}, timeout=60).json()
    if not r["ok"]:
        raise RuntimeError(r["error"])
    return r["data"]

last = 0
while True:
    for e in call("events.poll", after=last, wait=30)["events"]:
        last = e["event_id"]
        if e["kind"] == "message":
            m = e["message"]
            call("message.send", to=m["conversation"]["id"], text="You said: " + m["text"],
                 buttons=[[{"label": "👍 Nice", "data": "like"}, {"label": "Website", "link": "https://example.com"}]])
        elif e["kind"] == "button_press":
            call("button.reply", press=e["press"]["id"], notice="Thanks!")

Node.js (18+)

const API = '/api/bots/v2/';
const KEY = process.env.HUSHAVIA_KEY;

async function call(method, params = {}) {
  const r = await (await fetch(API + method, {
    method: 'POST', headers: { 'X-Bot-Key': KEY, 'Content-Type': 'application/json' }, body: JSON.stringify(params),
  })).json();
  if (!r.ok) throw new Error(r.error.message);
  return r.data;
}

(async () => {
  await call('commands.set', { commands: [{ name: 'start', about: 'Say hello' }] });
  let last = 0;
  for (;;) {
    const { events } = await call('events.poll', { after: last, wait: 30 });
    for (const e of events) {
      last = e.event_id;
      if (e.kind === 'message' && e.message.text === '/start') {
        await call('message.send', { to: e.message.conversation.id, text: 'Welcome! 👋' });
      }
      if (e.kind === 'member_joined') {
        const names = e.member_joined.people.map((p) => p.name).join(', ');
        await call('message.send', { to: e.member_joined.conversation.id, text: `Welcome ${names}! Please read the rules.` });
      }
    }
  }
})();

PHP — a hook (webhook)

<?php
$secret = getenv('HUSHAVIA_HOOK_SECRET');
$raw = file_get_contents('php://input');
$good = 'sha256=' . hash_hmac('sha256', $raw, $secret);
if (!hash_equals($good, $_SERVER['HTTP_X_HUSHAVIA_SIGNATURE'] ?? '')) { http_response_code(401); exit; }

$e = json_decode($raw, true);
if ($e['kind'] === 'message') {
    $ch = curl_init('/api/bots/v2/message.send');
    curl_setopt_array($ch, [CURLOPT_POST => true, CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => ['X-Bot-Key: ' . getenv('HUSHAVIA_KEY'), 'Content-Type: application/json'],
        CURLOPT_POSTFIELDS => json_encode(['to' => $e['message']['conversation']['id'], 'text' => 'Got it ✅'])]);
    curl_exec($ch);
}
http_response_code(200);

Turn the hook on once: hook.set with url = the address of this file (https). Save the secret it returns.

Already have a bot made with aiogram, grammY or a similar library?

Use the Classic API instead: those libraries work by changing only the server address, with the key written as <id>:<secret> (both forms are shown in @BotForge).

from aiogram.client.session.aiohttp import AiohttpSession
from aiogram.client.telegram import TelegramAPIServer
session = AiohttpSession(api=TelegramAPIServer.from_base("/api/classic"))
bot = Bot("123:yourSecretKey", session=session)

Use one way per bot at a time: a hook set through the Classic API sends Classic updates, one set with hook.set sends v2 events.

Rules

Bots must follow the Terms of Service (in the app: Settings → Help → Terms of service): no spam, scams or asking people for passwords, login codes or wallet words. Tell people what your bot stores about them. Bots that break the rules are switched off.
