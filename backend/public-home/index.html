Download help

Which Android APK should I choose?

Start with Download APK for a 64-bit Android phone. Choose the 32-bit APK for a phone running 32-bit Android.

Can I use Hushavia on iPhone or iPad?

Open Hushavia Web in Safari. To keep it on your Home Screen, use Safari’s Share menu and choose Add to Home Screen.

Which Windows download do I need?

Choose the installer for a Start menu shortcut, or extract the portable ZIP and run Hushavia from that folder.
